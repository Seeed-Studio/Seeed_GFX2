# reTerminal E1002 Color-Card Dither Selector

在同一张 800×480 测试色卡或 SD 卡照片上，比较 7 种抖动算法，支持**实时调参**、**评分**、**A/B 对比**，输出可直接复制的 `DitherConfig`。

> **这个工具不自动给算法打总分。** 以你**真实屏幕上的视觉结果**为最终判断依据。

## 两种模式各做什么

按 `i` 切换：

| | 色卡模式 | 照片模式 |
|---|---|---|
| **输入** | 嵌入式 800×480 测试色卡 | SD 卡上的真实照片 |
| **适合做** | 算法对比，淘汰明显有问题的 | 参数调优 + 最终选择 |
| **不适合做** | 调参数（纯色块上变化肉眼看不出） | 检验极端色（照片里纯色块太少） |

**典型流程**：先在色卡上淘汰不合适的算法，再在照片上挑最顺眼的。

> 扩散算法（FS/ATKINSON/BURKES/SIERRA3）在纯色块上收敛到几乎相同的混色比例，色卡上只有**品红**（ATKINSON 能逃出红锁）和**青色**（白点比例不同）能区分它们。颗粒度、肤色平滑度、天空过渡的差异只在照片上才看得见。

## 硬件与串口

- 产品：reTerminal E1002，800×480，XIAO ESP32-S3
- 调试串口：UART1，TX GPIO43，RX GPIO44，115200 baud
- 输出缓冲：4bpp，约 192000 字节
- SD 卡：共享 SPI，CS=GPIO14，EN=GPIO16
- **务必在开发板菜单中启用 OPI PSRAM**

## SD 卡照片准备

1. 将 SD 卡格式化为 FAT32，创建 `/img/` 目录
2. 放入一张 **JPEG/BMP/PNG** 照片，命名为 `demo.jpg`（自动缩放到 800×480）
3. 插入 SD 卡后启动。无 SD 卡时自动回退到嵌入式色卡

**照片选择建议**：用和你实际用途最接近的内容——风景（测天空/渐变）、人像（测肤色）、图表（测边缘）、插画（测平面色）。

## 五步工作流

### 第一步：建立视觉锚点

启动后页面 0 显示原生 6 色色条，**记住你的面板上白/绿/红/黄/蓝/黑实际长什么样**——这是后续所有判断的参照基准。

### 第二步：色卡淘汰

按 `1`–`7` 翻完 7 页，盯住这 5 个关键区域：

| 关键区域 | 位置 | 怎么看 | 预期 |
|---|---|---|---|
| 6 原色纯度 | 第 1 行 | 纯色块是否纯净无杂点 | 除 PALMIX 红块有 3% 黄点，其余 100% |
| 青色 | 第 3 行 CYAN | 应是蓝主导（不是绿主导） | FS/BURKES/SIERRA3 蓝 95–98%；ATKINSON 蓝 70% 白 7% |
| 橄榄绿 | 第 4 行 OLIVE | 黄绿黑混色，**无红污染** | FS/BURKES/SIERRA3 红 <1% |
| 品红 | 第 4 行最左 | 应是深紫（R+B 混） | PALMIX R64/B36；ATKINSON R72/B16；其余纯红 |
| 渐变 | 左右两侧 | 有无条带/网格 | NONE 有条带，BAYER8 有网格，其余平滑 |

每页按 `r` 评分（1–5），全部看完按 `m` 看汇总。

### 第三步：照片调参

按 `i` 切到 SD 照片模式，用 `g/G`（gamma）、`s/S`（饱和度）、`k/K`（暗度偏移）微调参数，每调一次自动重渲染。满意后按 `d` 恢复默认（1.10/0.20/0.00）。

### 第四步：A/B 对比

在两个候选算法页面分别按 `f` 标记，按 `t` 反复切换对比。

### 第五步：输出配置

按 `o`，串口输出可直接复制的 `DitherConfig`：

```cpp
DitherConfig cfg;
cfg.method = DITHER_FS;
cfg.palette = PAL_E6;
cfg.gamma = 1.15f;            // 你调出的最优值
cfg.invert = false;
cfg.serpentine = true;
cfg.saturationBoost = 0.25f;  // 你调出的最优值
cfg.darknessBias = 0.10f;     // 你调出的最优值
cfg.colorMetric = METRIC_RGB;
```

## 算法特性

| 算法 | 特点 | 注意 |
|---|---|---|
| **NONE** | 纯色块纯净，渲染最快 | 渐变有明显条带 |
| **BAYER8** | 图案稳定不抖动，边缘清晰 | 有规律网格纹理 |
| **FS** | 经典通用，4 抖点扩散最快 | 品红会锁红，颗粒感较重 |
| **ATKINSON** | 纹理最轻，品红能逃出红锁 (R72/B16) | 只扩散 75% 误差，暗区可能偏亮 |
| **BURKES** | 2 行缓冲省内存，比 FS 平滑 | 品红会锁红，颗粒略多于 SIERRA3 |
| **SIERRA3** | 颗粒最细，渐变过渡平滑 | 3 行缓冲占内存，品红会锁红 |
| **PALETTE_MIX** | 离群色最准——品红 R64/B36 深紫 | 有序纹理，纯色块有 3% 杂点 |

每种算法在纹理、颜色准确度、内存占用和渲染速度上各有取舍。**不确定选什么？** 从 SIERRA3 或 FS 开始，在照片模式下调参后和 ATKINSON、PALETTE_MIX 对比

## 全部串口命令

| 命令 | 功能 |
|---|---|
| `0` | 原生 E6 六色参考页 |
| `1`..`7` | 显示对应抖动算法 |
| `n` / `p` | 下一页 / 上一页 |
| `i` | 切换色卡 / 照片模式 |
| `g` / `G` | gamma +0.05 / -0.05 |
| `s` / `S` | saturationBoost +0.05 / -0.05 |
| `k` / `K` | darknessBias +0.05 / -0.05 |
| `d` | 恢复默认参数 (g=1.10, s=0.20, d=0.00) |
| `r` / `m` | 评分 1-5 / 打印汇总 |
| `f` / `a` / `b` / `t` / `x` | 候选标记 / 显示 A / 显示 B / 切换 / 清空 |
| `o` | 输出当前 DitherConfig |
| `c` / `v` | 进入 / 退出全屏校准模式 |
| `h` | 打印帮助 |

校准模式中 `1`–`6` 选色，`n`/`p`/空格 切换。

## 参数范围

| 参数 | 默认 | 范围 | 作用 |
|---|---|---|---|
| `gamma` | 1.10 | 0.30 ~ 2.50 | 整体亮度曲线（>1 变亮，<1 变暗） |
| `saturationBoost` | 0.20 | 0.00 ~ 1.00 | 颜色鲜艳度（越高越鲜艳） |
| `darknessBias` | 0.00 | 0.00 ~ 0.50 | 暗区补偿（>0 让阴影更亮） |

## 自定义调色板

**情况 A：校准同一块 E6 面板**（最常见）

用色度计在校准模式 (`c` 命令) 量出 6 色实测 RGB，填入 `kCalibratedE6_Rgb`，在 `makeConfig()` 中打开 `#define USE_CALIBRATED_PALETTE 1`。码字还是那 6 个——只让引擎知道真实 RGB 以便量化更准。

> 如果没有色度计，宁可不开校准（用默认 RGB），也不要填错的值。

```cpp
static const Rgb kMyPanelE6_Rgb[6] = {
    {252, 250, 248},  // WHITE
    { 40, 170,  50},  // GREEN
    {210,  30,  40},  // RED
    {250, 220,  20},  // YELLOW
    { 30,  80, 190},  // BLUE
    { 15,  15,  15},  // BLACK
};
static const uint8_t kMyPanelE6_Code[6] = {0x0, 0x2, 0x6, 0xB, 0xD, 0xF};
```

**情况 B：完全不同的调色板**（换面板）

码字和 RGB 都换，填入 `cfg.customPaletteRgb`/`customPaletteCode`/`customPaletteCount`。最多 16 色，码字 0–15。

### 库自带调色板

| 枚举值 | 颜色数 | 典型面板 |
|---|---|---|
| `PAL_BW` | 2（黑/白） | 单色 ePaper |
| `PAL_GRAY4` | 4 级灰 | 4 级灰 ePaper |
| `PAL_GRAY16` | 16 级灰 | 16 级灰 ePaper |
| `PAL_E6` | 6 色（白/绿/红/黄/蓝/黑） | Spectra C6 / E1002 |
| `PAL_BWRY` | 4 色（黑/白/红/黄） | ACeP 4 色面板 |

## 常见问题

**Q：色卡上 4 种扩散算法看起来几乎一样？**
A：正常。扩散算法在纯色块上收敛到相近的混色比例。按 `i` 切到照片模式比细微差别。

**Q：照片加载失败？**
A：检查：① SD 卡已插入；② 文件路径为 `/img/demo.jpg`；③ 格式为 JPEG/BMP/PNG。失败后自动回退到色卡。
