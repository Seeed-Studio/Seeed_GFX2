# E6 彩色电子纸抖动参数调优指南（reTerminal E1004）

> 配合 `reTerminal_E1004_SDcard_Color6_DitherCompare.ino` 示例使用
>
> E1002 版分屏是**左右**对比；E1004 是竖屏（1200×1600），本示例改为**上下**对比：
> 上半屏 = 新库（NEW），下半屏 = 旧库（LEGACY），中间隔 2 像素黑线。
> `a` / `b` 全屏模式把 1200×799 画面垂直居中显示（y=400），上下留白。
> 调参只影响新库（上半屏 / 按 `a` 全屏）。

---

## 串口命令速查（Serial Command Reference）

| 按键 Key | 参数 Parameter | 示例 Example | 范围 Range | 默认 Default |
|----------|---------------|-------------|-----------|-------------|
| `?` | 打印所有参数 / Print all | `?` | — | — |

| `d` | 暗度 / Darkness | `d0.08` | 0.0~0.5 | 0.0 |
| `t` | 对比度 / Contrast | `t1.15` | 0.5~2.0 | 1.0 |

**支持连续输入**：一行可以输入多个命令，用空格分隔，例如 `w0.2 t0.6 s0.3 d0.05`，会依次执行每个命令并自动刷新画面。

> Multiple commands can be chained on one line, e.g. `w0.2 t0.6 s0.3 d0.05`

**注意**：参数修改只影响新库（上半屏 / 按 `a` 全屏），旧库（下半屏 / 按 `b` 全屏）保持原始默认值不变，以保证公平对比。

> Only the NEW library is affected by parameter changes. The LEGACY library stays fixed.

## 各参数作用说明（Parameter Effect Summary）

| 参数 Parameter | 作用 Effect | 何时调大 When to increase | 何时调小 When to decrease |
|------|------|------------|------------|
| **Gamma** 伽马 | 整体亮度曲线 | 画面偏暗看不清细节 | 画面过曝/发白 |
| **Saturation** 饱和度 | 颜色鲜艳程度 | 色彩暗淡不鲜艳 | 颜色溢出/出现色块 |
| **Darkness** 暗度 | 抖动前预压暗 | 电子纸显示偏亮发灰 | 暗部死黑无细节 |
| **Contrast** 对比度 | 明暗层次分离 | 画面灰蒙蒙层次不清 | 高光过曝/暗部死黑 |
| **Diffusion** 扩散强度 | 误差传播比例 | 需要平滑渐变过渡 | 想要干净少噪点 |
| **Warmth** 色温 | 红蓝通道平衡 | 强调暖色调（落日等） | 强调冷色调（水面/蓝天） |
| **Clamp** 钳位 | 误差缓冲范围 | 纯色色块边缘更干净（`l` 开） | 照片渐变过渡更自然（`l` 关） |
| **Serpentine** 蛇形 | 之字形扫描 | 减少线条伪影 | 几何图案（`p` 关） |

## 各场景推荐参数

### 🌄 风景类（Landscape）

#### 山脉 / 大地色调（Mountains / Earth Tones）

```
m0  g1.0  s0.15  d0.06  t1.10  e1.0  w0.0
```

- **算法 Algorithm**：FS — 纹理和过渡最均衡 / balanced texture and smoothness
- **要点**：绿和蓝在 E6 调色板中表现较好，饱和度不用太高，否则绿色会溢出。泥土的棕色需要红+黄+黑混合，适当提高对比度有助于区分层次。
- **备选 Alternative**：`m2`（BURKES），岩石纹理更丰富。

#### 落日 / 金色时刻（Sunset / Golden Hour）

```
m3  g0.95  s0.25  d0.08  t1.20  e1.0  w0.20
```

- **算法 Algorithm**：SIERRA3 — 天空渐变最平滑 / smoothest sky gradients
- **要点**：🚨 **E6 没有橙色颜料！** 夕阳的橙红过渡必须靠红+黄抖动混合来模拟。`warmth=0.20` 至关重要——它让算法在红蓝交界处优先选择红色。提高对比度让天空渐变层次更分明。
- **备选 Alternative**：`m0`（FS），更快；如果天空偏红不自然，把 warmth 降到 0.15。

#### 森林 / 树木（Forest / Woodland）

```
m1  g1.0  s0.15  d0.10  t1.05  e1.0  w-0.05
```

- **算法 Algorithm**：ATKINSON — 树叶和枝干的细节清晰 / crisp detail for foliage
- **要点**：深绿色为主。`darknessBias=0.10` 防止暗部森林发灰。略微偏冷（`w=-0.05`）增强绿色表现。
- **备选 Alternative**：`m0`（FS），如果 Atkinson 纹理太粗糙。

#### 雪景 / 冬季（Snow / Winter）

```
m1  g1.05  s0.05  d0.02  t1.05  e0.9  w-0.05
```

- **算法 Algorithm**：ATKINSON — 白色干净 / clean whites
- **要点**：白色占主导。饱和度要非常低，否则雪地会出现不自然的色斑。降低扩散强度（`e=0.9`）让雪面更干净。略微偏冷。
- **备选 Alternative**：`m4`（BAYER8），海报化的冬日效果。

#### 水面 / 海洋 / 湖泊（Water / Ocean / Lake）

```
m3  g1.0  s0.20  d0.05  t1.10  e1.0  w-0.10
```

- **算法 Algorithm**：SIERRA3 — 水面渐变最平滑 / smoothest water gradients
- **要点**：蓝色是关键。负色温（`-0.10`）增强蓝色纯度。适当提高饱和度让蓝色在有限调色板中更突出。
- **备选 Alternative**：`m2`（BURKES），波浪纹理更丰富。

#### 风景类调参思路（Landscape Tuning Strategy）

| 参数 | 如果画面偏... | 调整方向 |
|------|-------------|---------|
| `w` 色温 | 夕阳不够"暖"、偏白 | 加到 0.15~0.30 |
| `w` 色温 | 蓝色天空发紫/偏色 | 降到 -0.05~0.05 |
| `w` 色温 | 水面/海洋不够蓝 | 降到 -0.10~-0.05 |
| `t` 对比度 | 天空渐变分层生硬 | 降到 1.0~1.05 |
| `t` 对比度 | 整体灰蒙蒙、山体没层次 | 加到 1.15~1.25 |
| `s` 饱和度 | 落日/秋叶色彩不够鲜艳 | 加到 0.25~0.35 |
| `s` 饱和度 | 雪景出现色斑、绿色溢出 | 降到 0.05~0.15 |
| `d` 暗度 | 暗部（山脉剪影/树林）发灰 | 加到 0.08~0.15 |
| `d` 暗度 | 暗部死黑无细节 | 降到 0~0.03 |
| `e` 扩散强度 | 噪点太多、画面不干净 | 降到 0.7~0.85 |
| `e` 扩散强度 | 天空色带/条纹明显 | 保持 1.0 |
| `g` 伽马 | 整体偏暗 | 加到 1.05~1.15 |
| `g` 伽马 | 天空过曝 | 降到 0.85~0.95 |
| `l` 钳位 | 远景山体边缘有伪影 | 保持关（宽钳位） |
| `p` 蛇形 | 地平线出现扫描纹理 | 保持开 |

### 🎨 动漫 / 插画类（Anime / Illustration）

#### 赛璐璐 / 平涂风格（Cel-shaded / Flat Color）

```
m4  g1.0  s0.10  d0.0  t1.05  e0.0  w0.0  l
```

- **算法 Algorithm**：BAYER8 — 干净有序的 Bayer 纹理 / clean ordered pattern
- **要点**：动漫有大面积纯色区域，误差扩散会产生不需要的噪点。BAYER8 提供干净有序的网点。`legacyClamp=开`（按 `l`）对纯色边界至关重要。BAYER8 不依赖扩散强度，`e` 无效。
- **备选 Alternative**：`m5`（NONE），纯最近色，零抖动，但可能丢失细微渐变。

#### 水彩 / 柔和渐变风格（Watercolor / Soft Gradient）

```
m2  g1.05  s0.15  d0.02  t1.05  e0.8  w0.05
```

- **算法 Algorithm**：BURKES — 平滑扩散，不产生粗糙纹理 / smooth without harsh texture
- **要点**：柔和插画有细腻渐变。降低扩散强度（`e=0.8`）减少噪点同时保持渐变平滑。略微偏暖增加手绘感。
- **备选 Alternative**：`m3`（SIERRA3），最平滑的渐变。

#### 黑白漫画（Manga / Black & White）

```
m1  g1.0  s0.0  d0.05  t1.15  e0.7  w0.0  l
```

- **算法 Algorithm**：ATKINSON — 经典黑白抖动纹理 / classic halftone texture
- **要点**：高对比、低扩散。Atkinson 的 75% 误差扩散产生经典的网版质感，非常契合漫画风格。`legacyClamp=开` 保证墨线干净。
- **备选 Alternative**：`m4`（BAYER8），网点纸效果。

#### 动漫类调参思路（Anime Tuning Strategy）

| 参数 | 如果画面偏... | 调整方向 |
|------|-------------|---------|
| `w` 色温 | 人物肤色偏冷/惨白 | 加到 0.05~0.15 |
| `w` 色温 | 冷色调角色发红 | 降到 -0.05~0.05 |
| `t` 对比度 | 线条不够黑、画面发虚 | 加到 1.10~1.20 |
| `t` 对比度 | 暗部细节丢失（如头发层次） | 降到 1.0~1.05 |
| `s` 饱和度 | 角色发色/服装不够鲜艳 | 加到 0.15~0.25 |
| `s` 饱和度 | 肤色出现红/黄色斑 | 降到 0.0~0.05 |
| `d` 暗度 | 白色背景发灰 | 加到 0.03~0.08 |
| `d` 暗度 | 深色头发/衣服死黑 | 降到 0~0.02 |
| `e` 扩散强度 | 纯色区域出现噪点 | 降到 0.6~0.8 |
| `e` 扩散强度 | 渐变背景出现条纹 | 加到 0.9~1.0 |
| `g` 伽马 | 整体偏暗看不清 | 加到 1.05~1.15 |
| `g` 伽马 | 高光溢出/白色过曝 | 降到 0.9~0.95 |
| `l` 钳位 | 色块边缘有杂色伪影 | 开（窄钳位） |
| `l` 钳位 | 渐变背景出现色带 | 关（宽钳位） |
| `p` 蛇形 | 大面积纯色出现斜纹 | 关 |

### 🐾 动物类（Animals）

#### 野生动物（Wildlife — fur, natural habitat）

```
m0  g1.0  s0.15  d0.06  t1.10  e1.0  w0.05
```

- **算法 Algorithm**：FS — 对皮毛纹理最均衡 / best all-rounder for fur
- **要点**：毛发细节需要适中的扩散。`warmth=0.05` 添加自然暖意，不夸张。`contrast=1.10` 帮助将动物与背景分离。
- **备选 Alternative**：`m2`（BURKES），厚毛动物纹理更丰富。

#### 鸟类 / 鲜艳羽毛（Birds / Colorful Plumage）

```
m3  g1.0  s0.25  d0.03  t1.15  e1.0  w0.10
```

- **算法 Algorithm**：SIERRA3 — 羽毛渐变最平滑 / smoothest feather gradients
- **要点**：鲜艳羽毛需要更高饱和度。红、蓝、黄、绿全在 E6 调色板内——鸟类是 E6 面板表现最好的题材之一。高对比度让颜色更跳。
- **备选 Alternative**：`m0`（FS），渲染更快。

#### 宠物（Pets — cats, dogs, indoor）

```
m0  g1.05  s0.10  d0.08  t1.05  e1.0  w0.10
```

- **算法 Algorithm**：FS — 室内光线下的毛发表现均衡 / balanced for indoor lighting
- **要点**：室内照片偏暗偏暖。`gamma=1.05` 提亮暗部。`darknessBias=0.08` 补偿电子纸偏亮。`warmth=0.10` 保留温馨的室内氛围。
- **备选 Alternative**：`m1`（ATKINSON），更锐利、细节更多。

#### 水下 / 鱼类（Underwater / Fish）

```
m3  g1.0  s0.30  d0.05  t1.10  e1.0  w-0.15
```

- **算法 Algorithm**：SIERRA3 — 水下渐变最平滑 / smoothest underwater gradients
- **要点**：高饱和度表现珊瑚和鱼的色彩。负色温保持蓝色水域干净。E6 蓝色表现力强，水下场景效果很好。
- **备选 Alternative**：`m2`（BURKES），珊瑚纹理更丰富。

#### 动物类调参思路（Animal Tuning Strategy）

| 参数 | 如果画面偏... | 调整方向 |
|------|-------------|---------|
| `w` 色温 | 皮毛偏冷/发灰 | 加到 0.05~0.15 |
| `w` 色温 | 蓝色羽毛/水域偏暖 | 降到 -0.10~0.0 |
| `t` 对比度 | 动物与背景分不开 | 加到 1.10~1.20 |
| `t` 对比度 | 深色皮毛细节丢失 | 降到 1.0~1.05 |
| `s` 饱和度 | 羽毛/鳞片色彩暗淡 | 加到 0.25~0.35 |
| `s` 饱和度 | 棕色皮毛出现红斑 | 降到 0.05~0.15 |
| `d` 暗度 | 深色动物（黑狗/黑猫）发灰 | 加到 0.10~0.15 |
| `d` 暗度 | 白色动物毛色变脏 | 降到 0~0.03 |
| `e` 扩散强度 | 皮毛纹理被噪点掩盖 | 降到 0.8~0.9 |
| `e` 扩散强度 | 羽毛渐变出现条纹 | 保持 1.0 |
| `g` 伽马 | 室内宠物照偏暗 | 加到 1.05~1.15 |
| `g` 伽马 | 雪地/白色动物过曝 | 降到 0.9~0.95 |
| `l` 钳位 | 动物轮廓有杂边 | 开（窄钳位） |
| `l` 钳位 | 皮毛渐变不自然 | 关（宽钳位） |
| `p` 蛇形 | 出现水平扫描纹理 | 保持开 |

### 👤 人像类（Portraits）

#### 单人 / 大头照（Single Person / Headshot）

```
m2  g1.0  s0.10  d0.05  t1.05  e0.9  w0.10
```

- **算法 Algorithm**：BURKES — 皮肤过渡平滑，比 FS 柔和 / smoother skin tones than FS
- **要点**：🚨 **E6 没有肤色颜料！** 肤色必须靠白+红+黄混合模拟，这是 E6 面板最难处理的题材。低饱和度（`0.10`）避免皮肤出现色斑。低扩散强度（`0.9`）减少面部颗粒感。`warmth=0.10` 保持皮肤自然。
- **备选 Alternative**：`m3`（SIERRA3），皮肤最平滑，但渲染更慢。

#### 合影（Group Photo）

```
m3  g1.0  s0.08  d0.05  t1.0  e1.0  w0.08
```

- **算法 Algorithm**：SIERRA3 — 最大程度保留多张面孔的细节 / maximum detail for multiple faces
- **要点**：合影中人脸面积小，每个像素都很关键。对比度保持中性（`1.0`），避免压碎面部特征。饱和度非常低，避免面部出现干扰色块。
- **备选 Alternative**：`m0`（FS），更快。

#### 时尚 / 棚拍（Studio / Fashion）

```
m1  g1.0  s0.15  d0.03  t1.10  e0.85  w0.05
```

- **算法 Algorithm**：ATKINSON — 干净利落的杂志质感 / crisp editorial look
- **要点**：棚拍背景干净、光线可控。Atkinson 的部分误差扩散产生利落的杂志风纹理。较高对比度增强时尚感。
- **备选 Alternative**：`m0`（FS）配合 `l`（钳位开），边缘最干净。

#### 人像类调参思路（Portrait Tuning Strategy）

| 参数 | 如果画面偏... | 调整方向 |
|------|-------------|---------|
| `w` 色温 | 肤色偏冷/惨白/发青 | 加到 0.10~0.20 |
| `w` 色温 | 肤色偏红像晒伤 | 降到 -0.05~0.05 |
| `t` 对比度 | 面部轮廓不立体 | 加到 1.05~1.15 |
| `t` 对比度 | 面部阴影太硬/显老 | 降到 1.0~1.05 |
| `s` 饱和度 | 嘴唇/气色不够红润 | 加到 0.15~0.20 |
| `s` 饱和度 | 面部出现红/黄色斑块 | 降到 0.0~0.08 |
| `d` 暗度 | 头发/眉毛发灰 | 加到 0.05~0.12 |
| `d` 暗度 | 眼窝/鼻翼阴影死黑 | 降到 0~0.03 |
| `e` 扩散强度 | 面部颗粒感重/皮肤粗糙 | 降到 0.8~0.9 |
| `e` 扩散强度 | 皮肤渐变出现色带 | 加到 0.95~1.0 |
| `g` 伽马 | 逆光/暗光人像偏暗 | 加到 1.05~1.15 |
| `g` 伽马 | 面部高光过曝 | 降到 0.9~0.95 |
| `l` 钳位 | 面部边缘/轮廓有杂色 | 开（窄钳位） |
| `l` 钳位 | 肤色过渡不自然 | 关（宽钳位） |
| `p` 蛇形 | 面部出现扫描纹理 | 保持开 |

### 🏙️ 城市 / 建筑类（City / Architecture）

#### 天际线 / 城市景观（Skyline / Cityscape）

```
m1  g1.0  s0.15  d0.05  t1.15  e0.9  w0.0  l
```

- **算法 Algorithm**：ATKINSON — 建筑线条清晰 / crisp architectural lines
- **要点**：建筑有大量直线。`legacyClamp=开` 和蛇形扫描关（如需要）使几何边缘更干净。高对比度增强建筑与天空的分离。
- **备选 Alternative**：`m4`（BAYER8），海报化的城市风格。

#### 夜景 / 霓虹灯（Night Scene / Neon）

```
m0  g1.2  s0.30  d0.15  t1.25  e0.8  w0.05
```

- **算法 Algorithm**：FS — 处理极端对比度效果好 / handles extreme contrast well
- **要点**：夜景暗部为主、高光亮点。`gamma=1.2` 整体提亮避免暗部死黑。`darknessBias=0.15` 让夜空呈现真正的黑色而非灰色。高饱和度表现霓虹灯光。低扩散减少暗部噪点。
- **备选 Alternative**：`m5`（NONE）——霓虹灯在黑背景上，零抖动反而非常干净。

#### 室内 / 博物馆 / 教堂（Indoor / Museum / Church）

```
m2  g1.05  s0.10  d0.08  t1.05  e1.0  w0.08
```

- **算法 Algorithm**：BURKES — 昏暗暖光下过渡平滑 / smooth for dim warm interiors
- **要点**：室内光线偏暖偏暗。`gamma=1.05` 轻微提亮。`darknessBias=0.08` 避免暗部发灰。保持暖色调保留环境光氛围。
- **备选 Alternative**：`m0`（FS），更快。

#### 城市类调参思路（City Tuning Strategy）

| 参数 | 如果画面偏... | 调整方向 |
|------|-------------|---------|
| `w` 色温 | 建筑/街景偏冷像阴天 | 加到 0.05~0.15 |
| `w` 色温 | 蓝天/玻璃幕墙不够蓝 | 降到 -0.05~-0.10 |
| `t` 对比度 | 建筑轮廓不清晰 | 加到 1.15~1.30 |
| `t` 对比度 | 窗户/暗部细节全黑 | 降到 1.0~1.05 |
| `s` 饱和度 | 霓虹灯/夜景灯光不够鲜艳 | 加到 0.25~0.35 |
| `s` 饱和度 | 建筑外墙出现色斑 | 降到 0.05~0.15 |
| `d` 暗度 | 夜景天空发灰不像黑色 | 加到 0.10~0.20 |
| `d` 暗度 | 暗部建筑完全没有细节 | 降到 0~0.05 |
| `e` 扩散强度 | 夜景暗部噪点多 | 降到 0.7~0.85 |
| `e` 扩散强度 | 天空渐变出现条纹 | 加到 0.9~1.0 |
| `g` 伽马 | 夜景/室内暗到看不清 | 加到 1.1~1.3 |
| `g` 伽马 | 白天场景天空过曝 | 降到 0.85~0.95 |
| `l` 钳位 | 建筑边缘有杂色伪影 | 开（窄钳位） |
| `l` 钳位 | 天空渐变出现色带 | 关（宽钳位） |
| `p` 蛇形 | 建筑竖直线条出现锯齿 | 关 |

## 快速上手流程（Quick-Start Workflow）

1. 将图片放入 SD 卡（建议横版约 3:2 比例的图片，与 1200×799 画幅最接近）
2. 烧录示例，默认显示上下分屏对比（`c`）查看基准效果
3. 按 `a` 切换到全屏新库，观察整图效果
4. 先选算法（`m0`~`m6`）——对画面风格影响最大
5. 根据图片类型调整关键参数（参考上面表格）
6. 微调，每次改完观察面板变化
7. 按 `b` 对比旧库，看优化了多少

### 推荐调参顺序（Recommended Tuning Order）

1. `m` — 算法 Algorithm（影响最大）
2. `w` — 色温 Warmth（纠正偏色）
3. `t` — 对比度 Contrast（定义明暗层次）
4. `s` — 饱和度 Saturation（颜色鲜艳度）
5. `d` — 暗度 Darkness（补偿电子纸偏亮）
6. `g` — 伽马 Gamma（微调亮度曲线）
7. `e` — 扩散强度 Diffusion（噪点 vs 平滑的取舍）
8. `l` / `p` — 开关项 Toggles（干净边缘 / 扫描方式）

## E6 调色板限制说明（E6 Palette Limitations）

E6 面板只有 6 种物理颜料：白、绿、红、黄、蓝、黑。以下常见颜色在调色板中缺失，需要通过参数补偿：

| 缺失颜色 Missing | E6 如何近似 How E6 approximates | 推荐参数补偿 Best parameter fix |
|---------|-----------|------------|
| **橙色 Orange** | 红 + 黄抖动混合 | `warmth` 0.15~0.30, `satBoost` 0.2~0.3 |
| **棕色 Brown** | 红 + 黄 + 黑混合 | `darknessBias` 0.05~0.10 |
| **肤色 Skin tone** | 白 + 红 + 黄混合 | `satBoost` ≤ 0.10, `diffStrength` 0.85~0.95 |
| **青色 Cyan** | 绿 + 蓝混合 | `warmth` -0.05~0.05, `satBoost` 0.15~0.25 |
| **紫色/品红 Purple** | 红 + 蓝混合 | 较难处理，降低 `satBoost` 减少伪影 |
| **粉色 Pink** | 白 + 红（无蓝） | `warmth` 0.05~0.15, 低 `contrast` |
